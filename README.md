# RealtimeLaundary-

## Folders

| Folder | What it is | Local address |
| --- | --- | --- |
| `Backend` | API server | http://localhost:5000 |
| `Frontend/User` | Customer app | http://localhost:5173 |
| `Frontend/Driver` | Driver app ([notes](Frontend/Driver/README.md)) | http://localhost:5174 |
| `Frontend/Admin` | Admin panel ([notes](Frontend/Admin/README.md)) | http://localhost:5175 |

## Run it

Each app runs in its own terminal. From the folder you want to start:

```bash
npm install
npm run dev
```
